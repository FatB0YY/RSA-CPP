# RSA на C++

Программа генерирует пару ключей RSA, шифрует строку побайтово и выводит результат расшифрования. Для вычислений с большими целыми числами используется `boost::multiprecision::cpp_int`. Решето, проверка на простоту, возведение в степень по модулю и расширенный алгоритм Евклида реализованы в [rsa.cpp](./rsa.cpp).

## Сборка и запуск

Понадобятся компилятор C++17 с поддержкой потоков и заголовочные файлы Boost для Multiprecision и Random. Выполните команды в каталоге с `rsa.cpp`.

```sh
g++ -std=c++17 -O2 -pthread rsa.cpp -o rsa
./rsa
```

1. Введите **длину модуля в битах**. Модуль — это произведение двух простых множителей. Если нажать **Enter**, программа выберет **2048 бит**. Можно ввести и нечётную длину, например `513`. Чем больше значение, тем дольше идёт генерация.
2. Когда программа выведет множители и оба ключа, введите сообщение и нажмите **Enter**. При расшифровании сохраняются пробелы и многобайтовый текст, в том числе кириллица в UTF-8.

Минимальная длина — 4 бита, поскольку наименьшее произведение двух различных нечётных простых чисел равно 15. При длине меньше 9 бит значение каждого байта сообщения должно быть меньше полученного модуля. Начиная с 9 бит в модуль помещается любое значение байта.

## Как работает алгоритм

1. **Отбор кандидатов.** Решето Эратосфена строит список простых чисел меньше 400. Два потока независимо генерируют нечётных кандидатов. Каждый поток проверяет малые делители, пока они не превысят квадратный корень из кандидата. Если делитель найден, поток выбирает новое число.
2. **Проверка на простоту.** Для каждого оставшегося кандидата больше 3 функция `isProbablyPrime` выполняет до 64 раундов теста Миллера — Рабина. В начале раунда `modularPower` возводит случайное основание в степень, равную нечётной части числа `candidate − 1`. Затем тест при необходимости возводит остаток в квадрат. Если кандидат проваливает хотя бы один раунд, проверка заканчивается.
3. **Вычисление ключей.** Если множители совпали или длина их произведения отличается от заданной, поиск повторяется. Программа вычисляет модуль `modulus = firstPrime * secondPrime` и значение функции Эйлера `eulerTotient = (firstPrime - 1) * (secondPrime - 1)`. Небольшая открытая экспонента выбирается случайно. Расширенный алгоритм Евклида проверяет, что она взаимно проста с `eulerTotient`, и находит обратное к ней число по модулю `eulerTotient`. Это число и есть закрытая экспонента.
4. **Шифрование и расшифрование.** Функция `modularPower` возводит значение каждого беззнакового байта в степень открытой экспоненты по модулю ключа. Шифроблоки попадают в очередь. Программа извлекает их по порядку, применяет закрытую экспоненту по тому же модулю и восстанавливает исходные байты.

## Один байт и 12-битный ключ

Возьмём простые числа 61 и 53. Их произведение равно 3233, а значение функции Эйлера — 3120. Открытая экспонента 17 и закрытая экспонента 2753 подходят друг другу, поскольку $17 \times 2753 \bmod 3120 = 1$.

| Операция                        | Вычисление                                    |
| ------------------------------- | --------------------------------------------- |
| Шифрование байта буквы `A` (65) | $65^{17} \bmod 3233 = 2790$                   |
| Расшифрование блока 2790        | $2790^{2753} \bmod 3233 = 65$, байт буквы `A` |

## Свойства шифрования

Каждый байт шифруется отдельно без случайного дополнения, поэтому при одном ключе одинаковым байтам соответствуют одинаковые шифроблоки. Программа также выводит в консоль простые множители и закрытый ключ. Из-за этих свойств она непригодна для защиты конфиденциальных данных. Стандартные схемы шифрования RSA описаны в [разделе 7 RFC 8017](https://datatracker.ietf.org/doc/html/rfc8017#section-7).
